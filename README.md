
# Rueda Libre - Proyecto Web (Semana 1 y Semana 2)

Sitio web informativo para Rueda Libre, un emprendimiento de Medellín enfocado en el alquiler de bicicletas, recorridos guiados diurnos y la nueva campaña de "Rueda Nocturna"[cite: 1, 2].

## Estructura del Proyecto
El repositorio contiene las siguientes secciones y versiones desarrolladas durante las prácticas:
- **`index.html`**: Página de inicio con carrusel de promociones, flota de bicicletas y enlaces principales[cite: 1].
- **`tarifas.html`**: Tablas accesibles con los precios de alquiler y rutas guiadas[cite: 1].
- **`reservas.html`**: Formulario con validación nativa y modal de confirmación[cite: 1].
- **`nocturna/`**: Landing page de la campaña "Rueda Nocturna" desarrollada con Tailwind CSS (CLI) y modo oscuro[cite: 2].
- **`bitacora.txt`**: Registro de pruebas, decisiones de diseño y comparativas de frameworks[cite: 1, 2].

## Tecnologías Utilizadas
- HTML5 semántico[cite: 1]
- CSS3 y diseño responsivo[cite: 1, 2]
- Bootstrap 5 (por CDN)[cite: 1]
- Tailwind CSS (vía CLI para la sección nocturna)[cite: 2]
- Git y GitHub Pages[cite: 1]
