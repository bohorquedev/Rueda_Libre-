Semana 2 (v1.5 a v2.0)

Tuve que hacer varios ajustes para que no saliera scroll horizontal a 360px.
- Comparativa CSS propio vs Bootstrap 5:
  * CSS propio (v1.5): me tomo cerca de 3 horas cuadrar las media queries y escribi unas 140 lineas de CSS.
  * Bootstrap 5 (v2.0): migrar todo me tomo 1 hora y el archivo styles.css quedo de solo 48 lineas porque use las clases de grilla (row, col) y utilidades de espaciado.
- En v2.0 agregue la navbar que colapsa en celular, el carrusel de promociones, las cards para la flota y la validacion de Bootstrap en el formulario con una alerta de error y un modal de confirmacion.
- Probe toda la pagina en DevTools a 360px, 768px y 1280px y navegue usando solo la tecla Tab para verificar que todo funciona bien.
